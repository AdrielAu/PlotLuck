# Plotluck

Where in London should your restaurant open? Plotluck scores every London postcode district (0 to 1) for how likely a restaurant of a given cuisine is to survive there, to help small independents and under-represented cuisines find their spot.

**Live site:** https://adrielau.github.io/PlotLuck/

## How it's built

A hybrid of two neural networks, trained and benchmarked on IBM LinuxONE (s390x) in Jupyter. The exported weights run in your browser on a static site, so there is no server and no LLM. Built for the IBM Z Datathon 2026 (Community Impact).
